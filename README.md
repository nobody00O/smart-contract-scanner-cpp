#  Smart Contract Risk & Vulnerability Scanner (C++ Engine)

A static analysis tool built in **C++** to evaluate Solidity smart contracts for critical security vulnerabilities (such as Reentrancy and unsafe `tx.origin` authentication). 

*Note: This project was created as a hands-on learning project to explore systems programming, cybersecurity, and Web3 security standards.*

 Features
- Fast file stream parsing implemented in standard C++.
- Pattern matching engine for high-risk Solidity constructs.
- Automated risk-scoring matrix with risk classification (Low, Medium, High).

 Requirements
- A modern C++ compiler supporting C++17 (`g++, clang++`, or MSVC).
- Make (optional, for convenience).
